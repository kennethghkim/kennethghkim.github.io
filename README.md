# kennethghkim.github.io

Portfolio of Kenneth Kim, Business Administration & Data Science student at Northeastern University (Finance concentration).

**Site:** https://kennethghkim.github.io

It covers project write-ups (a billing application, trade data analysis, equity research one-pagers, a financial reporting project, and an AI coding-agent harness), plus experience, coursework, and a resume PDF.

## Local preview

```
docker compose up -d
```

Then open http://localhost:4000.
